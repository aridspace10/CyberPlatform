Usage: grep [OPTION]... PATTERN [FILE]...
Search for PATTERN in each FILE (or standard input).

PATTERN uses Python's regular-expression syntax. An empty pattern matches
every line. With -w, a match must be bounded by non-word characters or the
start or end of a line; with -x, the entire line must match.

  -e PATTERN, --regexp=PATTERN  use PATTERN for matching
  -i, --ignore-case             ignore case distinctions
  -v, --invert-match            select non-matching lines
  -w, --word-regexp             match whole words
  -x, --line-regexp             match whole lines
  -o, --only-matching           print each non-overlapping match
  -n, --line-number             prefix output with line numbers
  -l, --files-with-matches      print names of files with a match
  -c, --count                   print selected line counts per input
  -H, --with-filename           prefix output with filenames
  -h, --no-filename             suppress filename prefixes
  -r, --recursive               search directories recursively
      --include=PATTERN         search only matching file names
      --exclude=PATTERN         skip matching file names
      --exclude-dir=PATTERN     skip matching directory names
      --help                    display this help and exit

Exit status is 0 when a line is selected, 1 when no line is selected, and 2
when an input or pattern error occurs. Errors are reported even with -c.
