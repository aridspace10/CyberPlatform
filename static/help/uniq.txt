Usage: uniq [OPTION]... [INPUT]
Filter adjacent matching lines from INPUT (or standard input).

With no INPUT, or when INPUT is -, read standard input.

  -c, --count           prefix each line with its group count
  -d, --repeated        print one line for each group with duplicates
  -f, --skip-fields=N   ignore the first N whitespace-separated fields
  -i, --ignore-case     ignore differences in case when comparing
  -s, --skip-chars=N    ignore the first N characters after skipped fields
  -u, --unique          print only lines from groups of one
      --help            display this help and exit

Fields are separated by runs of spaces or tabs. Skip fields are applied
before skipped characters. Comparison options do not change displayed lines.
