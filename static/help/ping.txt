Usage: ping [-c COUNT] [-W TIMEOUT] DESTINATION
       ping --help

Ping a destination in the simulated game network. The built-in destinations
are gateway (192.0.2.1, online) and offline-host (192.0.2.2, offline). Other
destinations can be added to the session's simulated NetworkManager.

Options:
 -c COUNT       send COUNT simulated requests (1 to 10; default 4)
 -W TIMEOUT     simulated response timeout in seconds (greater than 0, up to 60)

The online gateway replies deterministically in 10 ms. A timeout below 0.01
seconds produces timed-out requests. Offline destinations report unreachable.
The command completes immediately, reports packet statistics, and uses status
0 for all replies, 1 for packet loss, and 2 for an unknown destination. It does
not send real network traffic.
