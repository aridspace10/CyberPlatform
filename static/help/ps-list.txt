Usage:
 ps [-p PID[,PID...]] [-q PID[,PID...]] [-C COMMAND]

Selection options:
 -p PID[,PID...]      select process IDs
 -q PID[,PID...]      select process IDs (quick selection alias)
 -C COMMAND           select an exact command string

PID lists are comma-separated positive integers. Selections can be combined.
An empty selection prints the header and no process rows.
