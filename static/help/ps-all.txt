Usage:
 ps [-e|-A] [-l] [-p PID[,PID...]] [-q PID[,PID...]] [-C COMMAND]

Supported selection and output options:
 -e, -A               list all simulated processes (the default)
 -p PID[,PID...]      select one or more positive process IDs
 -q PID[,PID...]      alias for -p
 -C COMMAND           select an exact command string
 -l                   use the long output header

Output columns are PID, STATE, PPID, and COMMAND. Process states include
running, waiting_input, sleeping, and stopped. The scheduler removes completed
processes; the process listing also omits any terminated process awaiting its
next scheduler tick. The command never reads host-machine process data.
